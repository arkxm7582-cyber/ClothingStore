 Aura Loom - README

 About Aura Loom

Aura Loom is a modern fashion and lifestyle website focused on sustainability, craftsmanship, and authenticity. The platform highlights eco-friendly fashion values while offering users a stylish and clean browsing experience.

This project currently includes an **About Page** built with HTML, designed to showcase the brand story, mission, and core values.

 Project Structure

```bash
Aura-Loom/
│── about.html
│── style.css
│── script.js
│── index.html
│── shop.html
│── contact.html
```

 Features

* Responsive navigation bar
* Brand introduction section
* Core values showcase:

  * Sustainability
  * Craftsmanship
  * Authenticity
* Mission and story sections
* Clean and modern layout
* External CSS and JavaScript support

 Technologies Used

* HTML5
* CSS3
* JavaScript

 Getting Started

 1. Clone the Repository

```bash
git clone https://github.com/your-username/aura-loom.git
```

 2. Open the Project

Navigate to the project folder:

```bash
cd aura-loom
```

 3. Run the Website

Open `about.html` in your browser.
